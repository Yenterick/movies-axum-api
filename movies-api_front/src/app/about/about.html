El proyecto

De un CSV a una historia en vivo

01

Los datos

Partimos del dataset de TMDB: películas con su presupuesto, taquilla, votos, géneros, reparto y equipo. Un script los normaliza en 14 tablas relacionales de PostgreSQL.

02

La API

Un servicio REST en Rust con Axum y arquitectura hexagonal: CRUD completo de películas protegido con JWT, filtros, paginación y endpoints de analítica calculados en SQL.

03

La historia

Este frontend en Angular convierte cada consulta en un relato: cada gráfico trae su conclusión, y esa conclusión se recalcula cuando cambias el filtro o editas el catálogo.
